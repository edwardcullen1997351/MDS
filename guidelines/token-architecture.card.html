Do
Reference one tier up, never two. A component token is a rename of a semantic token, never a new value.
Do
Build new UI on semantic tokens. Reach for component tokens only to retheme a shipped component in isolation.
Never
A primitive in product code — var(--grey-200) renders right in light mode and wrong in dark.
Never
Mix foundations and tokens in one declaration: the value can be correct while the contract is missing.
