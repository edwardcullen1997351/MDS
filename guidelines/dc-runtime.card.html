Declarative Component Runtime (`dc-runtime`)

All 22 layout and interaction templates in Meridian are authored in the Declarative Component format (*.dc.html). This guide documents the runtime architecture, custom tag vocabulary, and lifecycle APIs executed by support.js.

Why Declarative HTML Templates?

Rather than requiring a full Node/bundler toolchain for every layout prototype or reference harness, templates are authored in static HTML files that parse custom tags and bind live React components at runtime. This allows instantaneous inspection in any browser while preserving 100% fidelity with the production React bundle.

2. Component Logic & Lifecycle

DCLogic API
§02

DCLogic Class

Every template includes a <script type="text/x-dc" data-dc-script data-props="..."> block containing a class extending DCLogic:

class Component extends DCLogic {
  state = {
    selected: null,
    loading: true
  };

  syncTheme() {
    const isDark = String(this.prop('theme', 'Light theme')).indexOf('Dark') === 0;
    document.documentElement.setAttribute('data-theme', isDark ? 'dark' : 'light');
  }

  componentDidMount() {
    this.syncTheme();
  }

  componentDidUpdate(prev) {
    if (this.props.theme !== prev.theme) this.syncTheme();
  }

  renderVals() {
    return {
      title: 'Active Work Orders',
      itemCount: this.state.items.length
    };
  }
}

3. Harness Inspector Integration

data-props JSON Schema
§03

Parametric Controls

The data-props attribute on the script tag defines the interactive control schema rendered by support.js in the harness panel:

  • Enums: {"editor": "enum", "options": ["Option A", "Option B"], "default": "Option A"}
  • Booleans: {"editor": "boolean", "default": true}
  • Ranges: {"editor": "range", "min": 0, "max": 2500, "step": 100, "default": 600, "unit": "ms"}
