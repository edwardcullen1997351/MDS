--anim-fade-out
Every exit is a straight fade
140ms · ease-in-out
Animate five properties only — opacity, transform: translate, background-color, border-color, box-shadow. Never height, never width, never anything that reflows.
Enter with direction, exit without. Dismissal never feels slower than the decision to dismiss.
Data never animates in. No counting-up numbers, no staggered rows — a count-up misrepresents state while it runs.
Every pattern collapses to 1ms under prefers-reduced-motion: reduce, handled in tokens/motion.css. No animation is load-bearing for meaning.
