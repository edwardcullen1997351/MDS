ScatterPlot Specification

Component: ScatterPlot Package: components/data/ScatterPlot.jsx Infrastructure: components/data/viz-core.js Standard: guidelines/data-visualization-spec-standard.card.html WCAG: Level AA Compliant

§01 Purpose & Domain Contract

ScatterPlot reveals observation-level relationships, distributions, associations, clustering, outliers, and multivariate structures between two or more quantitative/ordinal variables.

Domain Contract:
  • Observation-Level Records: Represents discrete records containing at least two continuous or ordinal dimensions ($x, y$).
  • When to Use: Use when detecting correlation strength, clustering anomalies (e.g. bearing wear vibration clusters), multivariate distributions (stroke rate vs pressure vs temperature), or sequential process phase cycles (connected trajectory).
  • When NOT to Use: Do NOT use for single aggregated category comparisons (use BarChart) or pure continuous time-series trajectories where individual observations are not the primary analytical entity (use LineChart).

§04 Included Variants

Variant Visual Encoding Primary Manufacturing Scenario
Standard Scatter 2D quantitative points with categorical color and distinct shape glyphs. CNC Spindle Speed (RPM) vs Vibration Amplitude (mm/s), isolating bearing degradation anomalies.
Bubble Plot 3-variable multivariate plot with true square-root area scaling. Press Stroke Rate (SPM) vs Hydraulic Pressure (bar) with Die Temperature as Bubble Size.
Connected Scatter Directed trajectory line connecting sequential observations across time or process steps. Continuous Carburizing Furnace cycle: Chamber Temperature (°C) vs Carbon Potential (%CP).
Jittered Scatter Categorical/ordinal axis with deterministic pseudorandom spatial displacement. Final Quality Inspection: Surface Roughness (Ra µm) clustered across 4 discrete Machining Cells.
Binned Density 2D grid of rectangular or hexagonal cells aggregating high-density observation counts. High-volume stamping telemetry (5,000+ parts) analyzing cycle time vs press tonnage clusters.

§06 Interactive & Visual States

  • Resting: Points rendered with 0.75 opacity + 1.2px white border for overlapping mark separation.
  • Hover / Pointer Over: Active point expands by 3px with dashed focus halo ring and pinned observation tooltip.
  • Selection: Clicking an observation locks selection ring (2.5px dark border) and emits onPointSelect callback.
  • Category Isolation: Clicking a legend item dims non-selected categories to 0.15 opacity.
  • Keyboard Active: Focused point displays high-contrast ring and live screen reader announcement.
  • Loading Skeleton: Shimmering sweep placeholder maintains chart coordinate frame during data loading.

§07 Area Scaling Mathematics & Jitter Policies

True Area Square-Root Proportionality:

In bubble charts, the human visual system perceives mark magnitude by area ($\pi r^2$), not radius ($r$). Scaling radius linearly causes a value of 4 to appear 16 times larger than a value of 1.

ScatterPlot strictly enforces square-root scaling via createAreaScale(): $$r(z) = r_{min} + \sqrt{\frac{z - z_{min}}{z_{max} - z_{min}}} \cdot (r_{max} - r_{min})$$

Deterministic Jittering:

Jittering uses a seeded linear congruential PRNG: $seed_{i+1} = (seed_i \times 9301 + 49297) \pmod{233280}$. This guarantees identical point spatial placement across re-renders and avoids disorienting layout shifts.

§09 Accessibility & Assistive Technology (WCAG 2.2 AA)

WCAG 1.4.1 (Non-Color Differentiation) Strict Compliance:

Categorical series must never be distinguished by color alone. ScatterPlot assigns distinct geometric shape glyphs (circle, square, diamond, triangle, cross, star) to each category, ensuring immediate readability for red-green and monochromatic color-blind operators.

  • ARIA Landmark: role="region", aria-roledescription="scatter plot", with descriptive aria-label.
  • Live Screen Reader Region: aria-live="polite" announces: "Observation 4 of 15: Bearing Alert. Spindle Speed: 2100 RPM, Vibration: 4.1 mm/s."
  • Full Tabular Parity: Built-in Alt+F11 semantic data table guarantees 100% information parity for non-visual assistive technology users.

§10 Motion & Transition Guidelines

  • Point Highlight Transitions: Hover scale and halo expansions execute within 150ms using cubic-bezier(0.16, 1, 0.3, 1).
  • Prefers Reduced Motion: When @media (prefers-reduced-motion: reduce) is active, point transitions and skeleton sweeps render instantly with 0ms duration.

§11 Content Rules & Number Formatting

  • Locale Convention: Default to Indian numbering system (en-IN, e.g. 2,400 RPM, 4.5 mm/s).
  • Regression Metrics: Slope, intercept, and $R^2$ correlation metrics formatted to 2–3 decimal places (e.g. $R^2 = 0.892$).
  • Axis & Tooltip Units: Explicit engineering telemetry units must be displayed on axis titles and in tooltip observation cards (RPM, mm/s, SPM, bar, °C, µm).

§12 Responsive Behavior & Container Constraints

  • Minimum Plot Bounds: Never compress plot area below $240 \times 160\text{px}$ to prevent extreme point clustering.
  • High-Volume Aggregation: For datasets with >1,000 observations on mobile viewports, automatically switch to variant="binned-density".

§13 Anti-Patterns & Misconfigurations

Strictly Prohibited Anti-Patterns:
  1. Radius-Linear Bubble Scaling: Scaling bubble radius proportional to value quadruples perceived visual area. Always use square-root area scaling.
  2. Color-Only Category Coding: Differentiating 3+ categories solely by color hue without shape glyphs violates WCAG 1.4.1.
  3. Non-Deterministic Jitter: Using Math.random() inside render loops causes points to jump erratically on every state change.
  4. Connecting Unordered Points: Never render lines between scatter points unless observations represent a true sequential trajectory cycle (Connected Scatter).

§14 Implementation & Developer Notes

  • Native React SVG: Implemented purely in React SVG without heavy external dependencies, importing shared math from viz-core.js.
  • ClipPath Bounding: All point marks and trendlines are contained within an SVG `` matching the plot dimensions.
