StockRunwayHorizon Specification (§01–§21)

Wave 3 — Data Visualization (High): 24px high micro-horizontal SVG bar visualization rendered inline within matrix rows and data grids.

§01 Geometric Layers & Visual Anatomy

  • Micro Height: Exactly 24px high (viewBox="0 0 100 24") designed for dense ERP matrix cells.
  • Segment 1 (Green): Safe stock coverage days (--ds-global-color-success-500).
  • Segment 2 (Yellow/Amber): Reorder threshold buffer zone (--ds-global-color-warning-500).
  • Vertical Marker (Red): Zero-stockout event date marker line with top flag/diamond notch (--ds-global-color-danger-500).
  • Hatch Pattern (Deficit): Diagonal stripe pattern representing zero stockout risk zone.
