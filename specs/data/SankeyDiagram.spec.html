Sankey Diagram Component Specification

Standard Specification Document for Multi-Stage Quantitative Flows & Transfer Networks
● status: frozen 9 Sep 2026 · 0 open items

§01 Purpose & Quantitative Transfer Intent

The SankeyDiagram component visualizes how quantities move, split, merge, or transform between sequential entities or operational stages. Unlike general node-link diagrams or static hierarchy trees, the primary visual encoding is the thickness of flowing ribbons, which directly represents flow magnitude.

  • Primary analytical questions: "Where does the energy/material enter, how does it distribute across intermediate processes, and what proportion is converted into useful output vs. loss/scrap?"
  • Contextual enterprise scenario: Plant electrical energy balances, raw steel coil mass flows, and industrial water circuits at Suryodaya Autocomp Ltd (Chakan plant PL-04, Pune).

§02 Data Model & Flow Conservation

Data is modeled as a directed graph comprising discrete stage nodes and positive weighted links: 

interface SankeyNode {
  id: string;              // Unique node ID
  label: string;           // Display name (e.g. "Grid 33kV")
  category?: string;       // Categorical color key
}

interface SankeyLink {
  source: string;          // Source node ID
  target: string;          // Target node ID
  value: number;           // Positive quantitative flow volume (> 0)
  category?: string;
}

// Flow Conservation Principle
Total Inflow(Node) = Sum(Link.value for Link.target == Node.id)
Total Outflow(Node) = Sum(Link.value for Link.source == Node.id)
Node Value = Max(Total Inflow, Total Outflow)

§03 Visual Encoding & Flow Ribbon Anatomy

Visual Channel Data Attribute Design & Scaling Rule
Link Ribbon Thickness Flow Volume (value) Linear scale: Link.thickness = Link.value * ky (where ky is the vertical pixels/unit ratio).
Node Bar Height Net Node Throughput Node.height = Max(Inflow, Outflow) * ky.
Horizontal Columns Stage / Temporal Sequence Left-to-right columns computed via DAG topological depth traversal.
Ribbon Fill / Gradient Source → Target Association Source-to-target smooth two-color linear gradient (#2563eb → #0d9488) with 0.55 default opacity.

§04 Component Composition & Layer Stacking

  1. Layer 0 (Canvas): SVG background viewport with linear gradients and pattern definitions.
  2. Layer 10 (Link Ribbons): Flow paths with source-target gradient fills and boundary strokes.
  3. Layer 20 (Stage Nodes): Vertical rectangular node bars with category color fills and 3px corner radii.
  4. Layer 25 (Hatch Textures): Transparent SVG monochrome hatch pattern overlays for non-color differentiation (WCAG 1.4.1).
  5. Layer 30 (Node Typography): Node titles and value metrics with background stroke halo for readability.
  6. Layer 50 (Inspection Overlays): Floating tooltip portal and accessible flow table modal (Alt+F11).

§05 Properties, Props & Configuration

Prop Type Default Description
nodes SankeyNode[] Required Array of entity nodes with IDs and labels.
links SankeyLink[] Required Array of directed weighted links between nodes.
align 'justify' | 'left' | 'right' | 'center' 'justify' Column alignment mode for sink nodes.
linkGradient boolean true Renders source-to-target smooth gradients along ribbons.
patternFills boolean true Overlays SVG monochrome hatch textures on nodes for color-blind accessibility.
unit string '' Flow measurement unit suffix (e.g. 'kWh', 'MT', 'kL').

§06 States & Interactions

  • Default State: All flow ribbons rendered at 55% opacity with smooth source-target gradients.
  • Hover / Focus State: Hovered node or link triggers full connected upstream/downstream path tracing; active ribbons brighten to 90% opacity with solid dark boundary strokes; all unrelated ribbons dim to 12% opacity.
  • Selection Lock: Clicking a node or link locks the highlighted pathway.

§07 Layout Algorithms & Geometry

The computeSankeyLayout() algorithm performs deterministic 5-stage partitioning: 

// 1. Column Topological Depth
Column(Node) = Max(Column(Parent_i) + 1) for all incoming Parent_i

// 2. Global Vertical Scale (ky)
ky = (PlotHeight - (MaxNodesInColumn - 1) * NodePadding) / MaxColumnCumulativeValue

// 3. Link Ribbon Stacking
OutLinks(Node).sort((a, b) => a.target.y - b.target.y)
InLinks(Node).sort((a, b) => a.source.y - b.source.y)

§08 Labeling, Collision & Density Rules

Labels on the first column anchor to the right of the node; labels on the final column anchor to the left; intermediate column labels center or float above to avoid overlapping dense ribbons.

§09 Responsive & Viewport Scaling

  • Fluid Column Spacing: Columns scale proportionally across available container width.
  • Link Decimation: Micro-flows (< 0.5% total volume) render with a minimum 1.5px visible ribbon width to preserve clickability.

§10 Accessibility & Dual-Encoding (WCAG 2.2 AA / AAA)

  • Explicit Textual Relationship: Tooltips and table modal provide explicit Source → Target: Quantity text (does not rely on color alone).
  • WCAG 1.4.1 (Non-Color Differentiation): Hatch patterns on nodes, distinct gradient ramps on links.
  • Keyboard Navigation: Roving focus between nodes (←/→/↑/↓) with Enter path locking.
  • Non-Spatial Modal Alternative: Alt+F11 accessible flow data table.

§11 Color Palettes, Tokens & Themes

Adheres to Meridian tokens: --viz-1 through --viz-6, --surface-card, and --border-subtle.

§12 Motion & Transitions

Ribbon opacity and node glow transition smoothly at 200ms ease.

§13 Anti-Patterns & Error Handling

  • ❌ Do NOT use for unweighted relations: Sankey diagrams require meaningful conservation weights.
  • ❌ Do NOT allow negative link values: Flow volume must be strictly non-negative.

import React from 'react';
import { SankeyDiagram } from '@meridian/design-system';

const energyData = {
  nodes: [
    { id: 'grid', label: 'Grid 33kV' },

    { source: 'grid', target: 'substation', value: 4100 },

  ]

  return (
    <SankeyDiagram
      nodes={energyData.nodes}
      links={energyData.links}
      unit="kWh"
      title="Plant Energy Balance"
      width={760}
      height={420}
    />
  );
}
