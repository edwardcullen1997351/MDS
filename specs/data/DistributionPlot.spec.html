DistributionPlot Specification

Component: DistributionPlot Package: components/data/DistributionPlot.jsx Infrastructure: components/data/viz-core.js Standard: guidelines/data-visualization-spec-standard.card.html WCAG: Level AA Compliant

§01 Purpose & Domain Contract

DistributionPlot describes the shape, empirical frequency, density, spread, central tendency, quantiles, and outliers of one or more quantitative distributions across discrete observation cohorts.

Variant Selection Contract:
  • Raw Observations Needed: Use Strip Plot or Dot Plot when every single individual part observation must remain visible and inspectable.
  • Empirical Frequency & Binned Counts: Use Histogram when users need to evaluate empirical counts across uniform interval bins.
  • Statistical Quantile Summary: Use Box Plot when comparing Tukey 5-number summaries (Min, $Q_1$, Median, $Q_3$, Max, Outliers) across multiple cohorts.
  • Continuous Shape & Modality: Use Violin Plot or Density Plot when detecting multi-modal distributions, skewness, or continuous probability densities.
  • When NOT to Use: Do NOT use for single aggregated category totals (use BarChart) or bivariate correlations between two independent variables (use ScatterPlot).

§03 Properties & Data Model

Prop Type Default Description
data Array<Record<string, any>> | number[] [] Array of observation objects or raw numeric values.
valueKey string 'value' Field key representing the continuous quantitative measure.
categoryKey string | null null Field key used to segment observations into comparative cohorts.
variant 'histogram' | 'box' | 'violin' | 'strip' | 'dotplot' | 'density' 'histogram' Statistical representation variant.
binCount number | null null Custom histogram bin count; defaults to Sturges' rule $k = \lceil\log_2 n + 1\rceil$.
bandwidth number | null null Kernel density estimation bandwidth; defaults to Silverman's rule $h = 1.06\sigma n^{-0.2}$.
toleranceBands Array<{ min: number, max: number, label?: string }> [] Engineering tolerance or specification window range bands.
referenceLines Array<{ value: number, label?: string, color?: string }> [] Nominal target, USL, LSL, or historical control limit reference markers.
showOutliers boolean true Renders individual outlier points lying beyond $1.5\times\text{IQR}$ in box plots.
showMean boolean true Renders arithmetic mean diamond mark inside box plots alongside median bar.

§04 Included Variants

Variant Statistical Representation Primary Manufacturing Scenario
Histogram Uniform empirical frequency bins with count heights. Press Shop Stamping Sheet Thickness Variation ($2.000\text{ mm} \pm 0.050\text{ mm}$) across 300 measured blanks.
Box Plot (Tukey) Min, $Q_1$, Median ($Q_2$), $Q_3$, Max, and $1.5\text{ IQR}$ outlier points. CNC Spindle Vibration Spread (mm/s) across 4 Machining Lines, isolating bearing degradation outliers.
Violin Plot Mirrored Gaussian KDE density envelope with embedded mini-box quartiles. Quench Tank Hardness (HRC) distributions across 3 Heat Treatment Batches, detecting bimodal furnace anomalies.
Strip Plot Jittered raw observation dots along categorical lanes preserving individual parts. Critical Transmission Shaft Surface Roughness (Ra µm) across 60 inspection points.
Dot Plot Stacked unit circle marks representing discrete frequency counts. Defect count frequency per machine line during shift changeover audits.
Continuous Density Smooth Gaussian KDE probability density curve with shaded area. Carburizing Furnace CCF-02 Temperature Stability continuous probability density around 850°C.

§06 Interactive & Visual States

  • Resting: Bins and boxes rendered with 0.75 fill opacity + overlaid pattern preset.
  • Hover / Pointer Over: Active bin/box expands slightly with high-contrast border and pinned statistical tooltip.
  • Group Isolation: Clicking a legend item dims non-selected groups to 0.15 opacity.
  • Keyboard Active: Focused distribution cohort displays high-contrast ring and live screen reader announcement.
  • Loading Skeleton: Shimmering sweep placeholder maintains chart coordinate frame during data loading.

§07 Statistical Transforms & Deterministic Policies

Sturges' Histogram Binning Rule: $$k = \left\lceil \log_2(n) + 1 \right\rceil, \quad w = \frac{\max(x) - \min(x)}{k}$$
Tukey 5-Number Quantiles & Outlier Thresholds: $$\text{IQR} = Q_3 - Q_1, \quad \text{Lower Fence} = Q_1 - 1.5\times\text{IQR}, \quad \text{Upper Fence} = Q_3 + 1.5\times\text{IQR}$$
Gaussian Kernel Density Estimation: $$\hat{f}(x) = \frac{1}{nh} \sum_{i=1}^n \frac{1}{\sqrt{2\pi}} \exp\left(-\frac{1}{2}\left(\frac{x - x_i}{h}\right)^2\right), \quad h = 1.06\sigma n^{-1/5}$$

§09 Accessibility & Assistive Technology (WCAG 2.2 AA)

WCAG 1.4.1 (Non-Color Differentiation) Strict Compliance:

Multi-cohort distribution comparisons overlay distinct SVG hatch patterns (PATTERN_PRESETS) onto fills and use distinct glyph markers for mean and outlier points.

  • ARIA Landmark: role="region", aria-roledescription="distribution plot", with descriptive aria-label.
  • Live Screen Reader Region: aria-live="polite" announces: "Distribution Line 3: Count 8, Median 3.10 mm/s, IQR 1.20 mm/s, Outliers: 4.80 mm/s, 5.40 mm/s."
  • Full Tabular Parity: Built-in Alt+F11 semantic data table guarantees 100% information parity for non-visual assistive technology users.

§10 Motion & Transition Guidelines

  • Cohort Isolation Transitions: Opacity and box height transitions execute within 150–200ms using cubic-bezier(0.16, 1, 0.3, 1).
  • Prefers Reduced Motion: When @media (prefers-reduced-motion: reduce) is active, all transitions execute instantly with 0ms duration.

§11 Content Rules & Number Formatting

  • Locale Convention: Default to Indian numbering system (en-IN, e.g. 2.000 mm, 4.5 mm/s).
  • Precision: Statistical quantiles formatted to 2–3 decimal places based on telemetry resolution.
  • Axis & Tooltip Units: Explicit engineering units declared in headers and tables (mm, mm/s, HRC, µm, °C).

§12 Responsive Behavior & Container Constraints

  • Narrow Viewports (<480px): Stack multi-cohort box plots vertically with increased spacing to prevent label collision.

§13 Anti-Patterns & Misconfigurations

Strictly Prohibited Anti-Patterns:
  1. Hiding Distributions Behind Averages Alone: Never report only mean $\pm$ standard deviation for skewed or bimodal distributions.
  2. Arbitrary Bin Widths: Avoid random histogram bin counts that artificially split or merge true empirical modes.
  3. Color-Only Cohort Distinction: Differentiating 3+ groups solely by color violates WCAG 1.4.1.
  4. Over-Smoothing KDE Curves: Setting KDE bandwidth too high conceals true bimodal quench anomalies.

§14 Implementation & Developer Notes

  • Native React SVG: Pure React SVG implementation without D3/Chart.js dependencies, importing statistical transform engines from viz-core.js.
  • Testable Transforms: All quantile, histogram, and KDE mathematical functions are modular, pure functions.
