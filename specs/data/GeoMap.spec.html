1. Purpose & Analytical Intent

The GeoMap component represents multi-dimensional datasets where geographic position, shape, distance, route, spatial topology, or territorial boundary is analytically meaningful. It serves to:

  • Analyze Spatial Distributions: Identify geographic clustering of plants, vendors, OEM customers, and container ports.
  • Examine Supply Chain Corridors: Evaluate multi-modal logistics flow volume, route transit duration, and bottleneck delays across highway/rail freight corridors.
  • Territory & Regional Yield Benchmarking: Visualize state-level manufacturing dispatches, regional scrap rates, and production quotas via choropleth fills.

2. Anatomy & Hierarchy

Element Type Description
Projection Engine Mathematical Core Translates spherical [Longitude, Latitude] coordinates into 2D SVG canvas [x, y] coordinates using Mercator or Equirectangular projections.
Region Polygons Choropleth Layer SVG path polygons representing territorial/state boundaries with fill values mapped to quantitative measures or status codes.
Hub Nodes Proportional Symbols Interactive markers placed at projected coordinates with semantic icons, capacity radii, status rings, and collision halos.
Freight Corridors Flow Links Curved quadratic bezier routes connecting source and target hubs with flow-weighted stroke widths, directional markers, and mode dashes.
Map Scale & Toolbar Spatial Controls Interactive zoom controls, pan gestures, search filter input, layer visibility toggles, and metric scale bar.

4. Visual Encoding & Aesthetics

  • Status Colors: Nominal (#16a34a), Warning (#d97706), Critical (#dc2626), Info (#2563eb).
  • Non-Color Differentiation: Critical regions utilize 45° diagonal hatch patterns (#hatch-critical), and Warning regions utilize 45° dashed hatch patterns (#hatch-warning) to strictly satisfy WCAG 1.4.1.
  • Corridor Weighting: Flow lines calculate stroke width using: strokeWidth = max(2, min(6, (flow / 10000) * 2)) with 3px white halo backing for high contrast over land polygons.
  • Hub Mark Elevation: Dropshadow filter (feDropShadow) and 2.5px white border halos ensure pin clarity on high-density displays.

5. Included Variants

  • hybrid (Default): Complete layered rendering displaying choropleth state boundaries, proportional hub nodes, and connecting freight corridors.
  • choropleth: Emphasizes regional boundaries and territorial metrics (e.g. state scrap rate variance, regional dispatch quotas).
  • bubble: Focuses exclusively on hub coordinates with radius scaled proportionally to facility throughput or capacity.
  • route: High-contrast logistics corridor view mapping inter-facility freight transfers, transit times, and transport modes (rail dashed, road solid).

6. Primitive & Core Component Composition

  • Primitives: Box, Text, Heading, Surface, Container.
  • Core Components: Tooltip (hover contextual metadata), Popover (hub drilldowns), Skeleton (data loading placeholder), EmptyState (zero-match search results).
  • Composite Components: Toolbar (zoom in, zoom out, reset view, layer toggles), SearchField (hub/route filter with auto-clear).

7. Visualization-Native Elements & Engine Math

The component incorporates Section 17 math from viz-core.js:

  • Mercator Projection Engine: Converts spherical coordinates $[\lambda, \phi]$ to 2D plane: 
    x = (width / 2) + scale * (lambda - lambda0);
y = (height / 2) - scale * (ln(tan(π / 4 + phi / 2)) - ln(tan(π / 4 + phi0 / 2)));
  • Quadratic Bezier Route Curves: Calculates normal offset midpoints to arc logistics corridors away from straight overlapping lines: 
    cx = mx + (-dy / dist) * dist * curvature;
cy = my + (dx / dist) * dist * curvature;
path = `M ${x0} ${y0} Q ${cx} ${cy} ${x1} ${y1}`;

8. Interactive Behaviors & Gestures

  • Pan & Zoom: Drag anywhere on the land surface to pan; click ＋ / － buttons or double click to zoom from 0.6x to 3.5x.
  • Live Filter: Typing in the search field dynamically isolates matching hubs and connecting corridors, dimming non-matching elements.
  • Selection Highlight: Clicking any hub or corridor triggers an animated dashed selection ripple ring and isolates connected upstream/downstream lanes.

9. Layout Templates & Responsiveness

  • Split View / Master-Detail: Left-hand map viewport paired with right-hand facility telemetry inspection cards.
  • Dashboard Layout: Fully responsive SVG viewBox maintaining aspect ratio across desktop (1080p, 1440p) and mobile tablet viewports.

10. Accessibility (WCAG 2.2 AA & Section 508)

  • WCAG 1.4.1 (Use of Color): Warning and Critical state polygons use distinctive SVG hatch line patterns in addition to color fills.
  • Accessible Table (Alt+F11): Full accessible HTML data table modal exposing all facility names, coordinates, capacities, corridor flows, transit times, and status levels for screen readers.
  • Keyboard Navigation: All hubs and corridors support keyboard focus ring (outline: 2px solid #0284c7) and Enter/Space trigger activation.

11. State Matrix & Edge Cases

Scenario Component Behavior
Empty Data / Zero Hubs Renders base territorial polygon backdrop with an informative EmptyState overlay.
Co-located Hubs (Overlap) Applies radial offset dispersion or cluster badges when two hubs share identical coordinates.
Missing Corridor Endpoints Gracefully skips invalid routes without crashing SVG rendering thread.

12. Performance & Rendering Budgets

  • Frame Budget: Smooth 60fps pan and zoom via CSS hardware-accelerated SVG group transforms.
  • Bundle Budget: Zero heavy external mapping libraries (No Leaflet or Mapbox dependencies); pure React + SVG rendering under 25KB.
