Heatmap Specification

Component: Heatmap Package: components/data/Heatmap.jsx Infrastructure: components/data/viz-core.js Standard: guidelines/data-visualization-spec-standard.card.html WCAG: Level AA Compliant

§01 Purpose & Domain Contract

Heatmap reveals patterns, anomalies, hotspots, correlations, and intensity gradients across two-dimensional categorical, ordinal, temporal, or discretized quantitative structures using cell fill intensity.

Domain Contract:
  • Two-Dimensional Grid: Evaluates bivariate discrete matrix structures (Row Category $\times$ Column Category) mapped to a third quantitative/categorical intensity measure.
  • When to Use: Use for dense pattern recognition, hotspot detection, cross-channel correlation matrices, or temporal activity schedules where individual exact values are secondary or available upon inspection.
  • When NOT to Use: Do NOT use for 1-dimensional categorical comparison against a single quantitative baseline (use BarChart) or continuous bivariate correlation between two independent quantitative variables (use ScatterPlot).

§04 Included Variants

Variant Visual Encoding Primary Manufacturing Scenario
Standard Matrix 2D categorical/ordinal grid mapping rows $\times$ columns with sequential color intensity. Machine Cell vs Shift Hour Thermal Load (°C) across 8 CNC machining centers over 24h.

§06 Interactive & Visual States

  • Resting: Cell fill rendered based on interpolated color scale with 1px subtle boundary border.
  • Hover / Pointer Over: Active cell highlighted with 2px high-contrast border and pinned inspection tooltip.
  • Selection: Clicking a cell locks selection ring and emits onCellSelect callback.
  • Missing / Downtime: Null or unavailable cells rendered with diagonal hatch pattern (#missing-hatch).
  • Keyboard Active: Focused cell displays 2px solid active border ring and live screen reader announcement.
  • Loading Skeleton: Shimmering grid placeholder maintains matrix layout during async query.

§07 Color Scale Mathematics & Missing Cell Policies

Perceptual Color Interpolation:

Linear RGB interpolation: $C(v) = \text{RGB}_1 + \frac{v - v_{min}}{v_{max} - v_{min}} (\text{RGB}_2 - \text{RGB}_1)$. For diverging scales, interpolation splits symmetrically around neutral zero $v_{neutral} = 0$.

Missing vs Zero Data Policy:

Missing cells and machine downtime periods must NEVER be rendered as zero values (which implies valid operating telemetry of 0.0). Missing cells MUST render with diagonal hatch lines.

§09 Accessibility & Assistive Technology (WCAG 2.2 AA)

WCAG 1.4.1 (Non-Color Reliance) Strict Compliance:

Color intensity cannot be the sole source of information. Heatmap enforces full accessibility parity by providing: (1) automated in-cell text values with contrast inversion, (2) pinned inspection tooltips, (3) semantic ARIA grid landmarks, and (4) Alt+F11 tabular matrix.

  • Luminance Contrast Inversion: When in-cell text is enabled, text color dynamically inverts between dark slate (`#0f172a`) on light cells and white (`#ffffff`) on saturated cells ($> 4.5:1$ contrast).
  • ARIA Grid Semantics: `role="grid"`, `role="row"`, `role="gridcell"`, with descriptive `aria-label`.
  • Live Screen Reader Region: `aria-live="polite"` announces: "Selected cell CNC-02, 14:00: 74 °C, High Thermal Load."

§10 Motion & Transition Guidelines

  • Cell Focus Transitions: Border highlights execute within 150ms using cubic-bezier(0.16, 1, 0.3, 1).
  • Prefers Reduced Motion: When @media (prefers-reduced-motion: reduce) is active, all transitions execute instantly with 0ms duration.

§11 Content Rules & Number Formatting

  • Locale Convention: Default to Indian numbering system (en-IN).
  • Precision: Correlation coefficients $r$ formatted to 2 decimal places (e.g. $r = 0.82$), temperature formatted to integer or 1 decimal.
  • Legend Scale Units: Explicit engineering units declared on legend gradient ramp (`°C`, `kg`, `r`, `kW`).

§12 Responsive Behavior & Container Constraints

  • Column Overflow: When column count exceeds available container width, enable horizontal scrolling container rather than compressing cells below 18px legibility threshold.

§13 Anti-Patterns & Misconfigurations

Strictly Prohibited Anti-Patterns:
  1. Rainbow / Jet Color Scales: Spectral color maps introduce artificial visual boundaries that distort linear intensity perception. Always use perceptual sequential or diverging scales.
  2. Mapping Missing Telemetry to Zero: Treating machine downtime as 0.0 creates false operational conclusions.
  3. Hardcoding Fixed Text Colors on Cells: Placing dark text on dark cells fails WCAG 1.4.3 contrast. Always use automated contrast inversion.

§14 Implementation & Developer Notes

  • Zero Heavy Dependencies: Native React and SVG implementation without D3 or Canvas dependencies, importing shared color scale interpolators from viz-core.js.
