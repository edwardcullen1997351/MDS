Range Chart Specification Standard

✓ status: frozen 9 Sep 2026 · 0 open items

1. Purpose & Analytical Intent

The RangeChart component represents data where the relationship, distance, or uncertainty between two quantitative endpoints (lower and upper bounds) is itself the primary analytical object. It is used to:

  • Analyze Bounded Tolerances: Evaluate physical tolerance bands (Lower Spec Limit, Upper Spec Limit) and central dimensions in CNC machining.
  • Track Before/After Transformations: Compare endpoint shifts (e.g. cycle time reduction before and after Kaizen interventions).
  • Communicate Statistical Uncertainty: Represent confidence intervals (e.g., 95% CI) around batch estimates.
  • Continuous Variation Envelopes: Visualize continuous thermal, pressure, or vibration bands over time.

2. Anatomy & Hierarchy

Element Type Description
Interval Connector / Bar Visual Mark The floating bar, link line, or shaded area connecting the lower and upper bounds.
Endpoint Marks Visual Anchor Whiskers, dots, or caps demarcating the discrete lower and upper boundary values.
Center Estimate Point Mark Optional central tick, diamond, or dot representing the mean, median, or measured sample value.
Target Baseline Reference Line Global reference line marking engineering targets or process specifications (e.g. nominal 50.000 mm).
Interval Semantics Metadata Semantic Label Explicit annotation declaring whether the range represents min-max, 95% CI, tolerance, or before-after delta.

3. Data Model & Input Contract

export type IntervalSemantics = 'min-max' | 'ci-95' | 'tolerance-band' | 'before-after' | 'target-actual' | 'custom';

export interface RangeDataItem {
  id?: string;
  label?: string;
  lower: number; // Lower bound / start value
  upper: number; // Upper bound / end value
  center?: number; // Central estimate (mean, median, actual)
  target?: number; // Engineering target / nominal
  status?: 'nominal' | 'warning' | 'critical' | 'info' | 'neutral';
  intervalSemantics?: IntervalSemantics | string;
  isImproved?: boolean; // For dumbbell directional change
  metadata?: Record;
}

export interface RangeChartProps {
  data: RangeDataItem[];
  variant?: 'interval-bar' | 'dumbbell' | 'error-bar' | 'range-area';
  orientation?: 'horizontal' | 'vertical';
  width?: number;
  height?: number;
  title?: string;
  subtitle?: string;
  unit?: string;
  targetLine?: number | { value: number; label?: string };
  showCenterEstimate?: boolean;
  showDirectLabels?: boolean;
  showControls?: boolean;
  showSearch?: boolean;
}

4. Visual Encoding & Aesthetics

  • Status Colors: Nominal (#16a34a), Warning (#d97706), Critical (#dc2626), Neutral (#64748b).
  • Dumbbell Directionality: Start nodes are rendered in neutral gray (#64748b); End nodes are color-coded in Emerald (#16a34a) if improved or Ruby (#dc2626) if regressed.
  • WCAG 1.4.1 Non-Color Differentiation: Critical bars feature 45° diagonal hatch lines (#rc-hatch-critical), and Warning bars feature 45° dashed hatch lines (#rc-hatch-warning).
  • Halo Elevation: SVG drop shadow filters (feDropShadow) and 1.5px white border halos ensure pin clarity on high-density displays.

5. Included Variants

  • interval-bar: Floating horizontal/vertical range bar bounded between lower and upper limits with optional central diamond/tick.
  • dumbbell: Two distinct endpoint markers connected by a link to highlight Before vs After or Planned vs Actual changes.
  • error-bar: Central estimate point (mean/median) with lower and upper uncertainty whiskers (e.g. 95% Confidence Interval).
  • range-area: Continuous chronological sequence / time-series shaded confidence envelope with a central trend line.

6. Primitive & Core Component Composition

  • Primitives: Box, Text, Heading, Surface, Container.
  • Core Components: Tooltip (hover contextual metadata), Skeleton (data loading placeholder), EmptyState (zero data or no search matches).
  • Controls: SearchField (filter categories), Sort selector (sort by spread, lower bound, upper bound, category name).

7. Visualization-Native Elements & Engine Math

The component incorporates Section 18 math from viz-core.js:

  • Domain Padding: calculateRangeExtents computes global min, max, span, and adds an 8% buffer to prevent endpoint clipping.
  • Spread & Delta Math: 
    spread = |upper - lower|;
delta = upper - lower;
pctChange = ((upper - lower) / |lower|) * 100;
  • Area Band Polygon: createRangeBandPath generates an enclosed SVG polygon connecting all upper boundary coordinates in forward order, and returning via lower coordinates in reverse order.

8. Interactive Behaviors & Gestures

  • Spread Sorting: Dynamically order categories by interval magnitude ($upper - lower$) to identify operations with highest variation.
  • Hover Inspection: Hovering any bar, dumbbell, or whisker displays a rich floating tooltip with lower/upper limits, spread, center estimate, and delta.
  • Row Selection: Clicking any category row triggers active selection highlighting and keyboard focus.

9. Layout Templates & Responsiveness

  • Horizontal Orientation: Ideal for long category names (CNC dimensions, press line operations).
  • Direct Labels: Direct numeric labels on endpoints prevent reading errors when navigating wide viewports.

10. Accessibility (WCAG 2.2 AA & Section 508)

  • WCAG 1.4.1 (Use of Color): Non-color diagonal hatch patterns distinguish warning and critical intervals.
  • Explicit Semantic Labels: Screen readers announce interval meaning (e.g. "Cylinder Bore: 95% CI from 82.49 to 82.52 mm, center 82.518 mm") rather than raw numbers.
  • Accessible Data Table (Alt+F11): Full accessible table modal exposing all category names, interval constructs, limits, center estimates, spreads, and status codes.

11. State Matrix & Edge Cases

Scenario Component Behavior
Zero Spread ($Lower = Upper$) Renders a discrete point / tick mark without crashing bar layout math.
Inverted Bounds ($Lower > Upper$) Normalized automatically via Math.min / Math.max with directional indicator.
Null / Missing Center Estimate Gracefully omits central point marker without disrupting the outer interval bar.

12. Performance & Rendering Budgets

  • Render Time: Sub-5ms initial SVG render for 100+ interval rows.
  • Bundle Budget: Zero external dependencies (No D3 or Chart.js); pure React + SVG rendering under 18KB.
