Gantt Chart Specification Standard

1. Purpose & Analytical Intent

The GanttChart component communicates temporal schedules by placing activities, manufacturing phases, tooling work orders, maintenance shutdowns, or machine resources as horizontal intervals on a common time scale. It is explicitly designed for schedule and duration analysis, not generic time-series metric measurements.

  • Schedule Coordination: Plan and track multi-phase activities across dates and shifts.
  • Critical Path Analysis: Trace predecessor-successor dependency chains to identify bottleneck tasks.
  • Progress & Overdue Tracking: Visualize percentage completion fills and flag delayed activities.
  • Milestone Gate Governance: Mark formal sign-offs, audits, and OEM handover gates.

2. Anatomy & Hierarchy

Element Type Description
Task Grid Table (Left Pane) Master View Scrollable list of task names, owners, phases, and percentage completion indicators.
Timeline Header Axis Temporal Grid Day, week, or month column headers with weekend shading and synchronized horizontal scrolling.
Duration Bars Interval Mark Horizontal bars spanning from start date to end date with progress overlay fills.
Milestone Diamonds Point Mark Zero-duration milestone diamonds placed at exact delivery or sign-off dates.
Dependency Connectors Flow Links Orthogonal SVG path lines with directional arrowheads connecting predecessor end dates to successor start dates.
Today Line Temporal Reference Vertical dashed reference line indicating current date and time.

3. Data Model & Input Contract

export type GanttVariant = 'basic' | 'progress' | 'dependency' | 'milestone' | 'grouped';
export type GanttZoomLevel = 'day' | 'week' | 'month';

export interface GanttTask {
  id: string;
  name: string;
  startDate?: string | Date | number;
  endDate?: string | Date | number;
  progress?: number; // 0 - 100%
  status?: 'nominal' | 'completed' | 'in-progress' | 'warning' | 'critical' | 'overdue' | 'scheduled';
  group?: string; // Phase or Work Center
  owner?: string;
  isMilestone?: boolean;
  milestoneDate?: string | Date | number;
  dependencies?: string[]; // Array of predecessor task IDs
  isCritical?: boolean;
}

export interface GanttChartProps {
  tasks: GanttTask[];
  variant?: GanttVariant;
  width?: number;
  height?: number;
  title?: string;
  subtitle?: string;
  showDependencies?: boolean;
  showProgress?: boolean;
  showTodayLine?: boolean;
  todayDate?: Date | string;
  defaultZoom?: GanttZoomLevel;
}

4. Visual Encoding & Aesthetics

  • Status Palettes: Completed/Nominal (#16a34a), In-Progress (#2563eb), Warning (#d97706), Overdue/Critical (#dc2626), Scheduled (#64748b).
  • Non-Color Differentiation: Overdue tasks use 45° diagonal hatch patterns (#gantt-hatch-overdue), Warning tasks use 45° dashed hatch patterns (#gantt-hatch-warn) to comply with WCAG 1.4.1.
  • Critical Path Connectors: Critical dependency arrows render in 2px Ruby red (#dc2626); standard dependencies render in 1.5px Slate gray (#94a3b8).
  • Today Marker: 2px dashed Sky blue line (#0284c7) with downward triangle indicator at the top timeline axis.

5. Included Variants

  • basic: Clean horizontal interval bars displaying task duration across project timeline.
  • progress: Bars with embedded percentage completion fills ($0-100\%$) and numerical badges.
  • dependency: Interactive orthogonal connectors routing predecessors to successors with arrowheads.
  • milestone: Emphasizes zero-duration checkpoint diamonds for project audits and customer gate sign-offs.
  • grouped: Hierarchical grouping by production line, project phase, or work center with collapsible headers.

6. Primitive & Core Component Composition

  • Primitives: Box, Text, Heading, Surface, Container, Stack.
  • Core Components: Tooltip (task hover details), Popover (dependency metadata), Skeleton (loading placeholder), EmptyState (zero task matches).
  • Composite Components: Toolbar (zoom toggles, search filter, table modal button).

7. Visualization-Native Elements & Engine Math

The component incorporates Section 19 math from viz-core.js:

  • Temporal Domain Calculation: calculateGanttDomain calculates global min/max timestamps and temporal padding: 
    minDate = min(task.startDate) - padDays * 86400000;
maxDate = max(task.endDate) + padDays * 86400000;
timeToX(t) = ((t - minDate) / (maxDate - minDate)) * timelineWidth;
  • Orthogonal Dependency Routing: createOrthogonalDependencyPath connects predecessor end coordinates to successor start coordinates with collision avoidance loops.

8. Interactive Behaviors & Gestures

  • Synchronized Scrolling: Scrolling either the left task table or the right timeline canvas maintains 1:1 vertical alignment across rows.
  • Zoom Level Switching: Instant toggle between Day, Week, and Month scales dynamically recalibrates column widths and date tick labels.
  • Live Filter: Search field filters tasks in real-time by task name, group, or owner.

9. Layout Templates & Responsiveness

  • Split View: Left-hand master task grid table (280px fixed width) paired with right-hand horizontally-scrollable timeline canvas.
  • Preserve Temporal Scale: Responsive horizontal scrolling ensures duration proportions are never distorted or compressed.

10. Accessibility (WCAG 2.2 AA & Section 508)

  • WCAG 1.4.1 (Use of Color): Overdue and warning tasks dual-encoded with monochrome diagonal hatch patterns.
  • Accessible Table (Alt+F11): Complete accessible HTML table modal exposing task names, start/end dates, progress %, predecessors, and status codes.
  • Keyboard Navigation: Interactive task selection and dependency navigation operates via keyboard focus without requiring mouse drag gestures.

11. State Matrix & Edge Cases

Scenario Component Behavior
Zero Duration (Milestone) Renders a discrete diamond marker instead of a zero-width bar.
Predecessor Behind Successor Dependency routing generates an outer orthogonal loop without visual clipping.
Overdue Schedule ($End < Today$) Applies warning/critical hatch patterns and overdue status pill.

12. Performance & Rendering Budgets

  • Frame Budget: Smooth 60fps horizontal scrolling via native DOM virtual scroll layers.
  • Bundle Budget: Pure React + SVG implementation under 22KB with zero third-party chart library dependencies.
