AreaChart Specification

Component: AreaChart Package: components/data/AreaChart.jsx Infrastructure: components/data/viz-core.js Standard: guidelines/data-visualization-spec-standard.card.html WCAG: Level AA Compliant

§01 Purpose & Domain Contract

AreaChart visualizes quantitative change across an ordered, usually temporal domain, specifically emphasizing accumulated magnitude, volume, or shifting composition (parts-to-whole).

Domain Contract:
  • Mandatory Ordered Domain: Observations along the X-axis must follow a strict, meaningful sequence (time, shift intervals, thermal ramp steps, frequency bins). Unordered categorical lists (e.g. regions, tool codes) are strictly forbidden; use BarChart instead.
  • When to Use: Use when total volume, cumulative envelope, or proportional composition across sequential time periods is the primary cognitive objective.
  • When NOT to Use: If the primary objective is comparing fine slopes, subtle rate changes, or when 4+ individual series intersect and overlap (which causes opaque occlusion), use LineChart.

§06 Interactive & Visual States

  • Resting: All series layers rendered with 0.85 fill opacity + overlaid pattern + 2px solid top boundary stroke.
  • Pointer Tracking: Crosshair line snaps to nearest X observation, displaying synchronized point markers and pinned multi-layer tooltip.
  • Series Isolation: Clicking a legend item dims non-selected series layers (0.25 opacity) and isolates the selected area layer for unhindered focus.
  • Keyboard Active: Roving focus indicator highlights active observation; screen reader announces exact metrics and percentage shares.
  • Loading Skeleton: Shimmering sweep placeholder maintains chart layout during async telemetry fetch.
  • Empty Telemetry: Standard empty state displaying notice when no telemetry is recorded for the selected shift or date range.

§07 Stacking Mathematics & Missing Data Policies

Stacking Engine Formulation:
  • Standard Stacked: $y_{0, s}(t) = \sum_{k=0}^{s-1} v_k(t)$, $y_{1, s}(t) = y_{0, s}(t) + v_s(t)$.
  • 100% Normalized: $S(t) = \sum_{k=0}^{M-1} |v_k(t)|$, $y_{0, s}(t) = \frac{\sum_{k=0}^{s-1} v_k(t)}{S(t)} \times 100$, $y_{1, s}(t) = y_{0, s}(t) + \frac{v_s(t)}{S(t)} \times 100$.
  • Stream Center: Baseline offset $y_{base}(t) = -\frac{1}{2} \sum_{k=0}^{M-1} v_k(t)$.
  • Missing Data Integrity: Telemetry interruptions must not be smoothed over with artificial curves. Missing timestamps must either explicitly record 0 or cleanly break the area polygon into disjoint intervals.

§09 Accessibility & Assistive Technology (WCAG 2.2 AA)

WCAG 1.4.1 (Non-Color Differentiation) Strict Compliance:

Color fills alone must never be the sole differentiator between stacked area series. AreaChart enforces this by overlaying SVG hatch, crosshatch, stipple, and stripe patterns (PATTERN_PRESETS) and drawing distinct 2px boundary strokes.

  • ARIA Landmark: role="region", aria-roledescription="area chart", with descriptive aria-label.
  • Live Screen Reader Region: aria-live="polite" announces: "Selected observation 3 of 12, time 10:00. Blanking 25 kg (21.6%), Stamping 58 kg (50.0%), Total: 116 kg."
  • Tabular Alternative: Built-in Alt+F11 data table guarantees 100% information parity for non-visual assistive technology users.

§10 Motion & Transition Guidelines

  • Path Interpolation Tweening: Transitions between series isolation or filter updates execute within 200–300ms using cubic-bezier(0.16, 1, 0.3, 1).
  • Prefers Reduced Motion: When @media (prefers-reduced-motion: reduce) is detected, all path transitions, crosshair fades, and skeleton sweeps are rendered instantly with 0ms duration.

§11 Content Rules & Number Formatting

  • Locale Convention: Default to Indian numbering system (en-IN, e.g. ₹1,45,000, 25,480 kWh).
  • Normalized Percentage Rounding: Stacked percentage shares must be formatted to 1 decimal place (e.g. 32.4%) and guaranteed to sum to exactly 100.0%.
  • Unit Suffixes: Always declare explicit engineering telemetry units in headers, axes, and tooltip rows (kWh, kg/hr, °C, SPM, bar).

§12 Responsive Behavior & Container Constraints

  • Container Width < 480px: Automatically reduce X-axis ticks to 3–4 items, wrap legend into vertical flow, and reposition tooltips below the active point.
  • Touch Devices: Supports touch scrubbing along the plot area with instantaneous crosshair sync and enlarged hit targets.

§13 Anti-Patterns & Misconfigurations

Strictly Prohibited Anti-Patterns:
  1. Overlapping Opaque Areas: Rendering multiple non-stacked areas with opaque fills causes severe visual obstruction. Always stack additive series or use LineChart for overlapping lines.
  2. Stacking Non-Additive Quantities: Never stack averages, percentages that do not represent parts of a whole, or temperature measurements (stacking 850°C and 820°C produces a nonsensical 1670°C).
  3. Excessive Series Clutter: Never exceed 5 stacked area series in a single chart. For >5 series, consolidate minor categories into an "Other" series.
  4. Smooth Curves Over Telemetry Blackouts: Never draw continuous bezier curves through periods of machine downtime.

§14 Implementation & Developer Notes

  • Zero Heavy Dependencies: AreaChart is implemented natively in React and standard SVG, consuming only the shared mathematical engine in viz-core.js.
  • ClipPath Safety: All area `` polygons are wrapped in an SVG `` bounding rectangle matching the plot region to prevent line bleeding outside margin bounds.
  • Fast Bisecting: Pointer move listener uses direct mathematical domain bisecting ($O(1)$ computation) rather than expensive DOM element hit tests.
