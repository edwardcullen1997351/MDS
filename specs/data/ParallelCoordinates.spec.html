Parallel Coordinates Specification Standard

1. Purpose & Analytical Intent

The ParallelCoordinates component visualizes high-dimensional datasets by projecting $N$ quantitative or ordered variables onto parallel vertical axes. Each observation record is rendered as a continuous polyline intersecting each axis at its dimensional value. It is reserved for genuinely high-dimensional comparison where simpler small multiples or scatter plots are insufficient:

  • Cluster Identification: Detect bundles of similar polylines reflecting shared operating regimes or quality classes.
  • Trade-Off & Pareto Frontier Analysis: Identify inverse relationships between adjacent dimensions (e.g. higher tonnage vs increased defect PPM).
  • Multidimensional Outlier Detection: Spot isolated polylines that deviate across multiple sensor channels simultaneously.

2. Anatomy & Hierarchy

Element Type Description
Parallel Dimension Axes Linear Axes Equally-spaced vertical lines representing individual quantitative variables with tick marks, labels, and units.
Observation Polylines Visual Mark Continuous straight or smooth cubic spline lines crossing each axis at the record's coordinates.
Axis Reordering Controls Interactive Control Left/Right nudge buttons and drag handles allowing analysts to place correlated dimensions side-by-side.
1D Range Brushes Filtering Layer Bounding range intervals on individual axes to isolate subset records meeting multi-criteria conditions.
Active Crosshairs Inspection Indicator Circles and numeric callouts placed at exact intersection points of the hovered polyline across all axes.

4. Visual Encoding & Aesthetics

  • Cluster Palettes: Sky Blue (#0284c7), Emerald Green (#16a34a), Amber Warning (#d97706), Purple (#7c3aed), Ruby Critical (#dc2626).
  • Polyline State Styling:
    • Active / Hovered: 3px solid high-contrast line with $100\%$ opacity and dropshadow filter.
    • Filtered / Background: 1px Slate-200 line (#e2e8f0) at $35\%$ opacity to maintain context without visual clutter.
    • Unselected: 1.5px colored line at $70\%$ opacity.

5. Included Variants

  • standard: Raw dimensional axes preserving physical engineering units (tons, bar, °C, MPa).
  • normalized: $0\% - 100\%$ min-max normalized scales across all axes for uniform slope comparison.
  • spline: Smooth cubic bezier curves connecting axes to reduce visual fatigue in dense datasets.
  • brushed: Interactive 1D range brushing to dynamically filter records across multiple dimensions.

6. Primitive & Core Component Composition

  • Primitives: Box, Text, Heading, Surface, Container.
  • Core Components: Tooltip (record multi-attribute inspection), Skeleton (loading placeholder), EmptyState (zero brush matches).
  • Composite Components: Toolbar (normalization toggle, spline toggle, brush modal trigger, table modal button).

7. Visualization-Native Elements & Engine Math

The component incorporates Section 20 math from viz-core.js:

  • Dimension Normalization: Maps raw values $v$ to $[0, 1]$ interval: 
    norm = (v - domain.min) / (domain.max - domain.min);
if (domain.inverted) norm = 1 - norm;
  • Smooth Cubic Spline Math: Connects adjacent axes using horizontal tangent control points: 
    cx1 = p0.x + (p1.x - p0.x) * 0.4;
cy1 = p0.y;
cx2 = p1.x - (p1.x - p0.x) * 0.4;
cy2 = p1.y;
path += ` C ${cx1} ${cy1}, ${cx2} ${cy2}, ${p1.x} ${p1.y}`;

8. Interactive Behaviors & Gestures

  • Axis Reordering: Clicking ◀ / ▶ buttons reorders adjacent axes to explore pairwise dimensional correlations.
  • Multidimensional Range Filtering: Setting min/max bounds instantly isolates passing polylines and mutes non-passing polylines.
  • Simultaneous Coordinate Inspection: Hovering any polyline illuminates active coordinate chips on all vertical axes simultaneously.

9. Layout Templates & Responsiveness

  • Split View: Top parallel coordinate plot paired with bottom inspection table.
  • Controlled Scrolling: For displays with $>8$ dimensions, horizontal SVG scroll preserves minimum 80px inter-axis spacing.

10. Accessibility (WCAG 2.2 AA & Section 508)

  • Non-Drag Range Controls: Accessible numeric input fields allow full keyboard filtering without requiring mouse drag gestures.
  • Accessible Data Table (Alt+F11): Full accessible table modal detailing all record dimensions, active brush filters, and clusters for screen readers.
  • Focus Highlights: High-contrast stroke halos ensure selected records remain legible to low-vision operators.

11. State Matrix & Edge Cases

Scenario Component Behavior
Missing Dimension Value ($null / NaN$) Interpolates to midpoint or bridges across adjacent dimensions without breaking path continuity.
Zero Variance Axis ($Min = Max$) Adds nominal $\pm 5\%$ span buffer to prevent division by zero in coordinate scaling.
Zero Passing Records (Over-filtered) Renders empty state overlay prompting operator to reset brush filters.

12. Performance & Rendering Budgets

  • Render Budget: Pure SVG path rendering handles 250+ simultaneous polylines at 60fps.
  • Bundle Budget: Zero heavy external mapping or charting libraries; pure React + SVG under 20KB.
