ConcurrentConflictResolver Specification (§01–§21)

Wave 3 — Interaction Pattern (Blocker): Non-destructive multi-user concurrency conflict resolution for enterprise manufacturing and planning workspaces.

§01 Problem & Behavioral Requirements

  • Version Collision Handling: When a shop-floor allocation or work order update fails due to an HTTP 409 / ETag version mismatch, the UI MUST NOT clear the planner's form or throw an unhelpful toast.
  • Side-by-Side Comparison: Opens a dedicated drawer displaying "Your Planned Change" alongside "Current System State".
  • 1-Click Resolution Pathways:
    1. Accept Remote & Re-calculate: Discards local change, pulls latest committed remote state, and updates inventory matrices.
    2. Force Override (Admin): Overwrites the remote state with the user's planned allocation under administrative authorization.
    3. Allocate Remaining Delta: Computes available delta (e.g., 150 kg requested - 100 kg reserved = 50 kg delta) and allocates only the remainder.

§03 Accessibility (WCAG 2.2 AA)

  • Implements role="dialog" and aria-modal="true".
  • Supports Escape key dismissal and backdrop dismissal.
  • Focus is trapped within the active drawer container while open.
