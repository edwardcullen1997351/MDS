Live, on Meridian's own components: planning at the Chakan plant (PL-04), where Anjali Deshmukh loads Deccan Machine Supply's September catalogue extract into the item master. Read the file, confirm the proposed mapping, then check 500 rows — the check writes nothing, and its verdict is exactly what the import commits. Four hundred and twelve parts will be created; eighty-eight rows come back with the rule that refused them, line by line. Change a mapping after the check to see the verdict go stale, switch existingRecords to upsert to see 41 collisions counted separately as overwrites, and use the harness switches for a write that stops at line 180, an import refused outright, an unknown outcome, and a file with no unit-of-measure column at all.
