Interaction patterns

Patterns index

An Interaction Pattern is a standardized way of solving a recurring interaction problem with existing components. It has no public API and nothing to install: what it specifies is the interaction contract the composition creates — sequencing, coordination, commit and cancel semantics, recovery. Each pattern ships three artifacts — a specification, a working reference implementation under templates/ set in a manufacturing ERP scenario, and do/don't visual pairs inside the sections whose rules they demonstrate — and each spec states at its foot which sections it omitted and why. Every scenario is set in the same works — Suryodaya Autocomp Ltd, Chakan plant (PL-04), Pune, in rupees and IST. See the interaction pattern spec standard for the section set, the include/omit tests, and what every pattern must ship; a fixed assembly with an API belongs in composite instead, and a screen frame in layouts.
