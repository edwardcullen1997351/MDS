- **Dates:** ISO `YYYY-MM-DD` (e.g., `2026-10-07`).
- **Phone:** `+91 98230 41185` (standard Indian mobile format with country code).
- **Part Numbers:** `BRK-4820-A`, `ENG-1029-C`, `PST-9481-B`.
- **Lot / NC / Work Order:** `WO-2026-0814`, `NC-7721`, `LOT-99201`.
