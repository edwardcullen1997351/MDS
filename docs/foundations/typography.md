# Typography Foundations

Meridian uses a dual-typeface system configured for readability in technical data environments.

---

## 1. Type Families
- **UI & Display:** Public Sans (`--font-sans`) — crisp geometry, high legibility.
- **Data & Monospace:** IBM Plex Mono (`--font-mono`) — used for part numbers, timestamps, lot numbers, hex values, tabular figures.

---

## 2. Type Scale
| Token | Size | Line Height | Usage |
| --- | --- | --- | --- |
| `--type-scale-1` | 11px | 14px | Micro labels, badges, table column headers |
| `--type-scale-2` | 12px | 16px | Dense table cells, secondary metadata |
| `--type-scale-3` | 13px | 18px | Standard UI body text, buttons, form inputs |
| `--type-scale-4` | 14px | 20px | Lead body, section card titles |
| `--type-scale-5` | 16px | 22px | Subheaders, modal titles |
| `--type-scale-6` | 18px | 24px | Section headers |
| `--type-scale-7` | 22px | 28px | Page titles |
| `--type-scale-8` | 28px | 34px | Top-level console hero / display |

---

## 3. Font Weights
- `--font-weight-regular`: 400 (standard body)
- `--font-weight-medium`: 500 (labels, table headers, buttons)
- `--font-weight-semibold`: 600 (card titles, page headers)
- `--font-weight-bold`: 700 (primary metrics, stat callouts)
