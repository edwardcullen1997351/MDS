# Meridian Design Principles

> Full reference standard: see root [Design Principles.md](file:///Design%20Principles.md).

## Core Principles Summary
1. **Dense, Light-First Console:** Designed for high information density without visual clutter.
2. **Hairlines over Shadows:** 1px borders carry structure; shadows are reserved for interactive elevations.
3. **Action Carried by One Blue:** Only interactive elements receive `--action-default`.
4. **Plant-Real Register:** All scenarios reflect real manufacturing ERP workflows at Suryodaya Autocomp Ltd (PL-04, Pune, IST).
5. **Deterministic Lifecycle:** Work orders, requisitions, lots, and parts transition through explicit, recoverable states.
